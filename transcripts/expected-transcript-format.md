# Expected Transcript Format

Use this transcript format:

```md
# Optional title

Speaker Name: Spoken text only. No Markdown inside dialogue.

Another Speaker: Spoken text only. Keep each speaker turn on one line or paragraph.

[pause 3 seconds]

Coach: Continue the conversation.
```

Rules:
- Dialogue lines must start with an unquoted speaker name or label followed by `:` (for example, `Coach:` or `Life Coach:`).
- Do not use Markdown formatting inside dialogue.
- Keep pauses as bracketed timing cues, like `[pause 3 seconds]`.
- Keep each speaker turn on one line or one paragraph.
